# Contao Qualli.Id Client
This extension is a plugin for Qualli.Id. It based on OAuth2 Login Bundle [contao-oauth2-client](https://github.com/markocupic/contao-oauth2-client) and contains a backend and frontend authenticator.

To use this plugin you need a license for Qualli.life.
